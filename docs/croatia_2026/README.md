# クロアチア＆スロベニア旅行 案内資料（2026年9月・母向け）

74歳の母に渡す、A4・全10ページの案内資料です。文字を大きめにし、
説明文よりも写真で現地の雰囲気が伝わることを優先しています。

## 使いかた

```sh
python3 build.py          # index.html を作る
```

`index.html` をブラウザで開き、**印刷 → 送信先「PDFに保存」→ 用紙A4・余白なし**
で、そのまま冊子になります（1セクション＝A4 1枚に固定してあります）。

### 写真を手元に取り込む（印刷用・おすすめ）

既定では写真をウィキメディア・コモンズから直接読み込むため、印刷時に
ネット接続が必要です。先に落としておくとオフラインでも崩れません。

```sh
python3 build.py --localize   # images/ に保存し index_offline.html を作る
```

### 写真リンクの確認

```sh
python3 verify_photos.py      # 全URLが開けるか確認（404が出たら要差し替え）
```

**この資料を作った環境は外部通信が遮断されていたため、URLの組み立てが
正しいことは確認済みですが、実際に画像が返ってくるかは未確認です。**
最初に一度これを流してください。

### レイアウトの確認

```sh
python3 check_fit.py          # 各ページがA4に収まっているか（要 Chrome）
```

文言を書き換えたあとは必ずこれを流してください。ページは
`overflow:hidden` で切り落とす作りなので、はみ出しても見た目では
気づけません。

## 直したいときは

内容はすべて `build.py` の先頭にまとまっています。

- `SPOTS` … 各観光地の見出し・紹介文・写真5枚・歩きかたのヒント
- `ITINERARY` … 2ページ目の日程表
- `ROUTE` … 3ページ目の乗り換え手順
- `COVER` … 表紙の写真

## 写真について

すべてウィキメディア・コモンズで自由な利用が認められている **実際に撮影された
写真** です。AIによる生成画像は使っていません。撮影者とライセンスは10ページ目
のリンク先で確認できます。

`photos.py` は、コモンズのファイル名から配信URLを組み立てます
（ファイル名のMD5の先頭2文字がディレクトリになる、という決まった規則）。
